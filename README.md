# Vanila Music Player

Музыкальный плеер на чистом HTML, CSS и JavaScript. Без фреймворков и сборки.

## Возможности

- Воспроизведение, пауза, предыдущий и следующий трек
- Случайный трек при открытии страницы
- Перемотка по клику на полосу прогресса
- Обложка вращается, пока трек играет
- Адаптивная вёрстка: на экране уже 480px карточка складывается в колонку, на более широком экране остаётся горизонтальная панель

## Структура

```
src/app/index.html    разметка
src/app/style.css     стили и медиазапросы
src/app/script.js     логика плеера и список треков
src/assets/music/     файлы .mp3
src/assets/images/    обложки .jpg
```
